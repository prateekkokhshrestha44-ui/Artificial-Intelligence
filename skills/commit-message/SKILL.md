---
name: commit-message
description: Conventions for writing git commit messages: summary line format, length, and body. Use when asked to write or improve a commit message.
---
Commit message rules:

1. First line: imperative mood, at most 50 characters, no trailing period ("Add ledger search").
2. Leave one blank line after the first line.
3. The body explains WHY the change was made, wrapped at about 72 characters.
4. One logical change per commit.
